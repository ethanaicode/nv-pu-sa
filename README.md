# 女菩萨 · X 博主精选画廊

这是一个面向公开信息的 **X（Twitter）关注列表精选画廊与博主备份存档**。项目内容来自线上站点 [nv-pu-sa.pages.dev](https://nv-pu-sa.pages.dev/)，用于保存和整理接口返回的公开资料，方便进行离线备份、数据核对与静态展示。

> **重要说明**：本项目仅作资料备份与存档使用，不代表或管理 X 平台上的任何账号，也不保证归档资料持续准确、完整或实时。请遵守当地法律法规、X 平台规则及内容版权要求。

## 项目内容

- `archive.json`：博主归档数据，包含从 X 平台获取的公开资料。
- `runtime-config.json`：运行时媒体配置及配置生成时间。
- 头像、封面等媒体资源通过数据中的 URL 或媒体代理地址引用。

每条归档记录可能包含以下信息：

- X 用户 ID、用户名和展示名称
- 头像、封面图地址
- 粉丝数量、认证状态
- 账号简介
- 是否被封禁或暂停等状态
- 备份时间与最后同步时间
- 画廊卡片、时间线和随机推荐等访问统计

## 数据用途

本仓库保存的是对线上接口数据的静态备份，适合用于：

- 公开账号资料的历史留档
- X 博主精选列表的数据核对
- 静态画廊或个人数据浏览器的本地数据源
- 研究公开网页接口返回数据的字段结构

数据不应被理解为实时数据库、官方账号目录或对任何账号的背书。项目不会因为归档某个账号而主张该账号、图片、文字或链接的所有权。

## 快速开始

本项目当前以 JSON 静态数据为主，不依赖后端数据库。可以直接读取归档文件：

```bash
jq 'length' archive.json
jq '.[] | {screen_name, name, followers_count, backed_up_at}' archive.json
```

也可以使用任意支持 JSON 的语言加载：

```js
const archive = await Bun.file("archive.json").json();
console.log(`归档账号数：${archive.length}`);
```

## 数据更新

更新归档时建议保留以下信息：

1. 记录数据获取时间和来源页面。
2. 保持现有字段名称与 JSON 类型稳定。
3. 不要把登录凭证、Cookie、私密接口响应或个人敏感信息提交到仓库。
4. 对失效、删除或状态变化的账号保留必要的历史标记，不要伪造实时状态。
